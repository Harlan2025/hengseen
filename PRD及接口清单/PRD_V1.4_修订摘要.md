# 衡简叙约 PRD V1.4 修订摘要

## 修订时间
2026-08-16

---

## 一、新增功能概览

| 功能模块 | 变更类型 | 核心内容 |
|---------|---------|---------|
| 用户协议和隐私政策勾选框 | 新增 | 注册/登录时勾选同意，后台可编辑内容 |

| 协议同意记录 | 新增 | 记录用户同意时间和版本 |

## 三、协议内容管理

### 3.1 后台编辑功能

**编辑界面：**
```
┌─────────────────────────────────────────┐
│     用户协议管理                         │
├─────────────────────────────────────────┤
│  协议类型：[用户协议 ▼]                  │
│                                         │
│  版本号：V1.0                           │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │ [B][I][U][S][List]...          │   │
│  │                                 │   │
│  │  欢迎使用衡简叙约...            │   │
│  │                                 │   │
│  │  一、协议范围...                │   │
│  │  二、用户权利...                │   │
│  │  三、隐私保护...                │   │
│  │                                 │   │
│  └─────────────────────────────────┘   │
│                                         │
│         [保存]  [预览]                  │
└─────────────────────────────────────────┘
```

**管理功能：**
- 支持富文本编辑（标题、段落、列表、链接等）
- 内容实时更新，前端无需重启
- 记录版本号（如 V1.0、V1.1）
- 记录最后更新时间

### 3.2 版本管理

**版本命名规则：**
- 主版本：V1.0 → V1.1 → V1.2...
- 大版本：V2.0（重大修改）
- 小版本：V1.0.1（修复性更新，可选）

**版本状态：**
- `active`：当前生效版本
- `inactive`：历史版本

## 四、新增接口（7个）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/agreements` | GET | 获取当前协议内容 |
| `/api/v1/auth/agreement-consent` | GET | 获取用户协议同意记录 |
| `/api/v1/admin/agreements` | GET | 获取协议列表（后台） |
| `/api/v1/admin/agreements/:id` | GET | 获取协议详情（后台） |
| `/api/v1/admin/agreements/:id` | DELETE | 删除协议版本（后台） |
| `/api/v1/admin/agreements` | POST | 创建新协议版本（后台） |
| `/api/v1/admin/agreements/:id` | PUT | 更新协议内容（后台） |
| `/api/v1/admin/agreements/:id/consents` | GET | 获取协议同意统计（后台） |

## 五、新增数据表（2张）

### 5.1 agreements（协议内容表）

| 字段 | 类型 | 说明 |
|------|------|------|
| agreement_id | uuid | 主键 |
| agreement_type | text | user_agreement/privacy_policy |
| title | text | 协议标题 |
| content | text | 协议正文（富文本） |
| version | text | 版本号（如V1.0） |
| is_active | boolean | 是否启用 |
| created_at | timestamptz | 创建时间 |
| updated_at | timestamptz | 更新时间 |
| updated_by | uuid | 更新人 |

### 5.2 user_agreement_consents（用户协议同意记录表）

| 字段 | 类型 | 说明 |
|------|------|------|
| consent_id | uuid | 主键 |
| user_id | uuid | 关联用户 |
| agreement_type | text | user_agreement/privacy_policy |
| version | text | 同意的协议版本 |
| agreed_at | timestamptz | 同意时间 |
| ip_address | text | IP地址 |
| device_info | text | 设备信息 |
| is_current | boolean | 是否为当前生效版本 |

## 七、前端交互规范

### 7.1 协议弹窗展示

**弹窗样式：**
- 标题：字体加粗，字号16px
- 正文：字体14px，行高1.6
- 滚动区域：最大高度400px
- 底部按钮：「我知道了」

**交互逻辑：**
1. 点击「用户协议」或「Privacy Policy」链接
2. 弹出模态框展示协议内容
3. 内容支持滚动查看
4. 点击「我知道了」关闭弹窗

### 7.2 协议版本更新提示

**场景：** 用户登录后，系统检测到协议版本已更新

**提示弹窗：**
```
┌─────────────────────────────────────┐
│     用户协议已更新                   │
│                                     │
│  我们更新了《用户协议》和《隐私政策》，│
│  请您重新阅读并同意。               │
│                                     │
│  [查看更新内容]  [不同意]            │
│                                     │
└─────────────────────────────────────┘
```

**处理逻辑：**
- 点击「查看更新内容」：打开协议详情弹窗
- 点击「不同意」：强制退出登录，提示「需要同意最新协议才能继续使用」
- 点击「我知道了」：记录同意，进入系统

## 八、合规要求

### 8.1 法律合规
- 注册/登录前必须明确同意用户协议和隐私政策
- 记录用户同意时间和版本，作为法律证据
- 协议内容需符合《网络安全法》《个人信息保护法》要求

### 8.2 用户体验
- 协议内容清晰易懂，避免冗长晦涩
- 提供便捷的查阅入口
- 版本更新时友好提示

### 8.3 数据安全
- 同意记录加密存储
- 记录IP地址和设备信息
- 防止伪造同意记录
