## 十、人工服务模块（新增）

### 10.1 获取项目专家列表
- **接口**：`GET /api/v1/projects/:project_id/experts`
- **描述**：获取项目绑定的专家联系人列表
- **响应**：
```json
{
  "code": 0,
  "data": {
    "experts": [
      {
        "expert_id": "uuid",
        "expert_name": "张律师",
        "title": "商事合同专家",
        "wechat": "zhang_lawyer",
        "qq": "123456789",
        "email": "zhang@example.com",
        "tags": ["合同纠纷", "股权投资"],
        "added_by": "uuid",
        "created_at": "2026-08-16T10:00:00Z"
      }
    ]
  }
}
```

### 10.2 添加专家联系人
- **接口**：`POST /api/v1/projects/:project_id/experts`
- **描述**：为项目添加专家联系人
- **请求体**：
```json
{
  "expert_name": "张律师",
  "title": "商事合同专家",
  "wechat": "zhang_lawyer",
  "qq": "123456789",
  "email": "zhang@example.com",
  "tags": ["合同纠纷", "股权投资"]
}
```
- **响应**：
```json
{
  "code": 0,
  "data": {
    "expert_id": "uuid"
  }
}
```

### 10.3 修改专家信息
- **接口**：`PATCH /api/v1/projects/:project_id/experts/:expert_id`
- **描述**：修改专家联系方式
- **请求体**：
```json
{
  "wechat": "new_wechat_id",
  "email": "new@example.com"
}
```

### 10.4 删除专家联系人
- **接口**：`DELETE /api/v1/projects/:project_id/experts/:expert_id`
- **描述**：删除项目中的专家联系人
- **响应**：
```json
{
  "code": 0,
  "data": {
    "success": true
  }
}
```

### 10.5 复制专家联系方式
- **接口**：`POST /api/v1/projects/:project_id/experts/:expert_id/copy`
- **描述**：复制专家联系方式到剪贴板（防爬虫）
- **请求体**：
```json
{
  "field": "wechat"
}
```
- **响应**：
```json
{
  "code": 0,
  "data": {
    "value": "zhang_lawyer",
    "copied_at": "2026-08-16T12:00:00Z"
  }
}
```

## 十一、支付模块（新增）

### 11.1 创建支付订单
- **接口**：`POST /api/v1/projects/:project_id/orders`
- **描述**：创建导出合同文本的支付订单
- **响应**：
```json
{
  "code": 0,
  "data": {
    "order_id": "uuid",
    "amount": 5.99,
    "token_cost": 1.50,
    "price_tier": "fixed",
    "expires_at": "2026-08-16T12:30:00Z",
    "wechat_qr_url": "https://.../qr.png",
    "alipay_qr_url": "https://.../qr.png",
    "alipay_order_string": "https://qr.alipay.com/xxx"
  }
}
```

### 11.2 查询订单状态
- **接口**：`GET /api/v1/orders/:order_id`
- **描述**：查询支付订单状态
- **响应**：
```json
{
  "code": 0,
  "data": {
    "order_id": "uuid",
    "status": "paid",
    "amount": 5.99,
    "paid_at": "2026-08-16T12:05:00Z",
    "download_unlocked": true
  }
}
```

### 11.3 微信支付回调（服务端接收）
- **接口**：`POST /api/v1/payments/wechat/callback`
- **描述**：微信支付异步通知（由微信服务器调用）
- **请求头**：
  - Wechatpay-Signature: 签名
  - Wechatpay-Timestamp: 时间戳
  - Wechatpay-Nonce: 随机串
- **请求体**：
```json
{
  "id": "event_id",
  "type": "refund.notify.v2",
  "timestamp": "1710000000",
  "nonce": "random_string",
  "data": {
    "out_trade_no": "order_id",
    "transaction_id": "wechat_transaction_id",
    "amount": {
      "total": 599,
      "currency": "CNY"
    },
    "success_time": "2026-08-16T12:05:00Z"
  }
}
```
- **响应**：
```json
{
  "code": 0,
  "msg": "success"
}
```

### 11.4 支付宝回调（服务端接收）
- **接口**：`POST /api/v1/payments/alipay/callback`
- **描述**：支付宝异步通知
- **请求参数**：表单参数（alipay签名验证）
- **核心字段**：
  - out_trade_no: 订单ID
  - trade_no: 支付宝交易号
  - total_amount: 实付金额
  - trade_status: TRADE_SUCCESS

### 11.5 获取支付二维码
- **接口**：`GET /api/v1/orders/:order_id/qr`
- **描述**：获取支付二维码图片
- **响应**：
```json
{
  "code": 0,
  "data": {
    "wechat_qr_url": "https://.../qr.png",
    "alipay_qr_url": "https://.../qr.png",
    "alipay_url": "https://qr.alipay.com/xxx"
  }
}
```

### 11.6 取消订单
- **接口**：`POST /api/v1/orders/:order_id/cancel`
- **描述**：用户主动取消支付订单
- **响应**：
```json
{
  "code": 0,
  "data": {
    "status": "cancelled"
  }
}
```

## 十四、支付对接说明

### 14.1 微信支付接入

**必要条件：**
- 微信公众号或小程序已认证
- 开通微信支付功能
- 获取商户号（mch_id）
- 配置API密钥（api_key）
- 配置支付回调地址

**核心流程：**
```
1. 后端调用微信统一下单API
2. 获取prepay_id
3. 生成二维码内容（微信支付码）
4. 前端展示二维码
5. 用户扫码支付
6. 微信异步回调通知
7. 后端验证签名，更新订单状态
8. 解锁下载权限
```

### 14.2 支付宝接入

**必要条件：**
- 支付宝商家账号
- 开通当面付/电脑网站支付功能
- 获取APPID和私钥
- 配置支付宝公钥

**核心流程：**
```
1. 后端调用支付宝统一收单API
2. 生成二维码字符串
3. 前端展示二维码或使用支付宝SDK
4. 用户扫码支付
5. 支付宝异步通知
6. 后端验签，更新订单状态
7. 解锁下载权限
```

### 14.3 安全注意事项

1. **签名验证**：所有回调必须验证签名，防止伪造请求
2. **幂等处理**：同一订单重复回调只处理一次
3. **金额校验**：回调中的金额必须与订单一致
4. **日志记录**：完整记录支付流水，便于对账
5. **异常监控**：支付失败率、回调延迟等指标监控

## 十五、AI服务对接说明

### 15.1 推荐模型配置

**环境变量配置：**
```bash
# DeepSeek（推荐主模型）
AI_API_KEY=sk-xxxxx
AI_BASE_URL=https://api.deepseek.com/v1
AI_MODEL=deepseek-chat

# 备用模型
AI_FALLBACK_MODEL=qwen-plus
AI_FALLBACK_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

# 结构化输出模型
AI_JSON_MODEL=deepseek-coder
```

### 15.2 调用示例（Python）

```python
from openai import AsyncOpenAI
import os

client = AsyncOpenAI(
    api_key=os.getenv("AI_API_KEY"),
    base_url=os.getenv("AI_BASE_URL")
)

async def generate_contract(facts, outline, risks):
    prompt = f"""
    请根据以下信息生成一份完整的买卖合同：
    
    【已确认事实】
    {facts}
    
    【大纲结构】
    {outline}
    
    【风险提示】
    {risks}
    
    要求：
    1. 使用规范的法律语言
    2. 高风险条款标注⚠️
    3. 末尾附风险提示章节
    4. 包含免责声明
    """
    
    response = await client.chat.completions.create(
        model=os.getenv("AI_MODEL", "deepseek-chat"),
        messages=[
            {"role": "system", "content": "You are a professional legal document generator."},
            {"role": "user", "content": prompt}
        ],
        temperature=0.3,
        max_tokens=4000
    )
    
    return response.choices[0].message.content
```

### 15.3 成本优化策略

1. **上下文压缩**：只传递关键要素，去除冗余对话历史
2. **分段生成**：主体和附录分开生成，减少单次Token消耗
3. **模型选择**：简单任务用低价模型（deepseek-chat），复杂任务用高质量模型
4. **缓存复用**：行业通用条款预置，减少生成量

### 15.4 监控指标

| 指标 | 说明 | 告警阈值 |
|------|------|---------|
| 单次调用成本 | 每个接口的Token消耗 | > 0.5元 |
| 日总成本 | 当日AI服务总费用 | > 100元 |
| 超时率 | 响应超过30秒的比例 | > 5% |
| 错误率 | AI服务返回错误的比例 | > 2% |
