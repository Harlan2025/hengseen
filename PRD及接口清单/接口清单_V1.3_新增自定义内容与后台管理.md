## 十二、用户自定义内容模块（V1.3新增）

### 12.1 获取项目自定义内容列表
- **接口**：`GET /api/v1/projects/:project_id/custom-contents`
- **描述**：获取项目中的所有自定义内容
- **响应**：
```json
{
  "code": 0,
  "data": {
    "contents": [
      {
        "content_id": "uuid",
        "chapter_id": "uuid",
        "content_type": "custom",
        "content": "【用户自定义】本合同项下货物包装应采用防潮材料...",
        "inserted_at": "2026-08-16T12:00:00Z"
      }
    ],
    "total": 3,
    "max_limit": 10
  }
}
```

### 12.2 插入自定义内容
- **接口**：`POST /api/v1/projects/:project_id/custom-contents`
- **描述**：插入一条自定义内容
- **请求体**：
```json
{
  "chapter_id": "uuid",
  "content": "【用户自定义】本合同项下货物包装应采用防潮材料，确保运输安全。"
}
```
- **响应**：
```json
{
  "code": 0,
  "data": {
    "content_id": "uuid",
    "total_count": 4
  }
}
```
- **注意**：超出10条限制时返回错误码4003

### 12.3 修改自定义内容
- **接口**：`PATCH /api/v1/projects/:project_id/custom-contents/:content_id`
- **描述**：修改自定义内容
- **请求体**：
```json
{
  "content": "【用户自定义】修改后的内容..."
}
```

### 12.4 删除自定义内容
- **接口**：`DELETE /api/v1/projects/:project_id/custom-contents/:content_id`
- **描述**：删除自定义内容
- **响应**：
```json
{
  "code": 0,
  "data": {
    "success": true
  }
}
```

### 17.1 模板沉淀触发机制（V1.3新增）

#### 17.1.1 使用次数统计
```sql
-- 统计系统总使用次数（已完成导出且支付成功的订单数）
SELECT COUNT(*) as total_usage
FROM payment_orders
WHERE status = 'paid'
  AND created_at >= DATE_TRUNC('month', CURRENT_DATE);
```

#### 17.1.2 模板生成触发
当 `total_usage >= 1000` 时，自动触发模板沉淀任务：

```python
# 伪代码
async def check_template_trigger():
    usage_count = await get_total_usage()
    if usage_count >= 1000 and not is_template_unlocked():
        await trigger_template_沉淀()
        await unlock_template_feature()
```

#### 17.1.3 AI模板提炼流程
```python
async def generate_template(source_contracts):
    prompt = f"""
    请分析以下{len(source_contracts)}份历史合同，提炼出通用的合同模板结构：
    
    {source_contracts}

    1. 提取高频章节结构
    2. 提炼标准条款表述
    3. 去除个性化内容
    4. 输出JSON格式模板

    response = await ai_client.chat.completions.create(

    return response.choices[0].message.content
```

## 十八、后台管理接口说明

### 18.1 定价配置接口

**接口：PUT /api/v1/admin/pricing-config**

**用途**：管理员动态调整定价策略

**修改项说明**：
- `fixed_threshold`：固定价格阈值（默认2元）
  - 低于此阈值的合同按固定价格收费
  - 高于此阈值的合同按成本倍数收费
- `fixed_price`：固定价格（默认5.99元）
  - 简单合同的固定收费金额
- `multiplier`：倍数系数（默认2倍）
  - 复杂合同的收费倍数

**生效时间**：修改后立即生效，无需重启服务

### 18.2 模板管理接口

**接口列表**：
- `GET /api/v1/admin/contract-templates` — 获取合同模板列表
- `POST /api/v1/admin/contract-templates/:id/review` — 审核合同模板
- `GET /api/v1/admin/clause-templates` — 获取条款模板列表
- `POST /api/v1/admin/clause-templates/:id/review` — 审核条款模板

**审核状态**：
- `pending`：待审核
- `approved`：审核通过，可投入使用
- `rejected`：审核驳回

### 18.3 退款处理接口

**接口列表**：
- `GET /api/v1/admin/refunds` — 获取退款申请列表
- `POST /api/v1/admin/refunds/:id/process` — 处理退款申请

**处理流程**：
1. 客服查看退款申请详情
2. 审核退款理由
3. 执行退款操作
4. 记录处理结果

## 十九、自定义内容接口说明

### 19.1 插入限制
- 单个项目最多插入 **10条** 自定义内容
- 超出限制返回错误码 4003

### 19.2 插入位置
- `chapter_id`：指定插入到哪个章节
- 为空表示自由插入，由用户手动定位

### 19.3 内容格式
- 建议以 `【用户自定义】` 开头
- 系统自动识别并标记

### 19.4 编辑权限
- 插入者本人可编辑、删除
- Admin可管理所有自定义内容
