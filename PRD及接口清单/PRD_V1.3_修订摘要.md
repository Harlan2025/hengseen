## 二、用户自定义内容模块

### 2.1 功能设计

**插入方式：**
1. **章节级插入**：选择目标章节，点击「插入自定义内容」
2. **自由插入**：在合同文本编辑模式下，自由选择插入位置
3. **模板片段插入**：达到1000次后可从片段库选择

**数据结构：**
```json
{
  "content_id": "uuid",
  "project_id": "uuid",
  "chapter_id": "uuid",
  "content_type": "custom/fragment",
  "content": "【用户自定义】自定义条款内容...",
  "inserted_by": "uuid",
  "created_at": "2026-08-16T12:00:00Z"
}
```

**使用限制：**
- 每个项目最多 **10条** 自定义内容
- 自定义内容不参与风险评估
- 导出时在合同中用 `【用户自定义】` 标识

**接口列表（4个）：**
- `GET /projects/:id/custom-contents` — 获取列表
- `POST /projects/:id/custom-contents` — 插入内容
- `PATCH /projects/:id/custom-contents/:id` — 修改内容
- `DELETE /projects/:id/custom-contents/:id` — 删除内容

## 三、专家信息公开

### 3.1 变更内容
- 原设计：专家联系信息仅项目成员可见
- 新设计：**专家联系信息允许公开**，其他用户可查看并复制

### 3.2 合规要求
- 专家公开前需经用户确认
- 专家有权删除自己的公开信息
- 系统记录信息公开同意时间

### 3.3 数据结构变更
```json
{
  "expert_id": "uuid",
  "project_id": "uuid",
  "expert_name": "张律师",
  "wechat": "zhang_lawyer",
  "is_public": true  // 新增字段
}
```

## 四、退款策略

### 4.1 处理流程
```
用户提交退款申请（理由、订单号）
    ↓
客服审核（1-3个工作日）
    ↓
审核通过 → 执行退款 → 通知用户
审核驳回 → 告知原因
```

### 4.2 接口列表（2个）
- `POST /orders/:id/refund` — 申请退款
- `GET /refunds/:refund_id` — 查询退款状态

### 4.3 状态定义
| 状态 | 说明 |
|------|------|
| pending | 待处理 |
| approved | 已批准，等待退款执行 |
| rejected | 已驳回 |
| processed | 已处理完成 |

## 五、动态定价配置

### 5.1 配置项说明

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| fixed_threshold | 2.0 | 固定价格阈值（元） |
| fixed_price | 5.99 | 简单合同固定价格（元） |
| multiplier | 2.0 | 复杂合同倍数系数 |
| currency | CNY | 货币单位 |

### 5.2 定价逻辑
```
if token_cost <= fixed_threshold:
    price = fixed_price
else:
    price = token_cost * multiplier
```

### 5.3 接口列表（2个）
- `GET /admin/pricing-config` — 获取配置
- `PUT /admin/pricing-config` — 更新配置

### 5.4 生效方式
- 修改后立即生效
- 无需重启服务
- 记录修改人和修改时间

## 七、1000次触发模板沉淀机制

### 7.1 触发条件
当系统累计使用次数达到 **1000次** 后，开始沉淀服务期合同数据并生成合同模板、条款模板。

### 7.2 数据收集规则
- **统计周期**：按自然月统计
- **数据来源**：已完成导出且支付成功的订单
- **脱敏处理**：移除当事人信息、敏感商业数据
- **存储位置**：`contract_templates` 表、`clause_templates` 表

### 7.3 模板生成流程
```
达到1000次使用
    ↓
后台启动模板沉淀任务
    ↓
AI分析历史合同数据
    ↓
提炼合同模板结构
    ↓
提炼高频条款表述
    ↓
生成候选模板
    ↓
管理员审核
    ↓
审核通过 → 入库
审核驳回 → 删除候选
```

### 7.4 使用限制
- 模板功能在达到1000次后自动解锁
- 解锁前显示提示：「使用已达X次，即将开放模板库」
- 解锁后可选择「使用模板」快速生成合同

### 7.5 统计接口
- `GET /admin/stats/usage` — 获取使用次数统计
- 返回字段：total_usage, current_month, threshold, progress_percent, template_unlocked
