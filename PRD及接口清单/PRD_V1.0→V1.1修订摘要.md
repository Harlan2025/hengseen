## 二、核心修订详情

### 2.1 匿名用户流程（新增 §2.6）

**流程设计：**
```
访问 → 无需登录 → 创建项目 → 访谈 → 生成合同
    ↓
点击「下载/复制」→ 触发登录弹窗
    ↓
[登录] → 绑定匿名项目 → 同步历史项目
```

**关键决策：**
- 匿名用户可用范围：创建、访谈、查看大纲风险
- 需登录才能使用：下载合同、复制条款
- 登录后自动关联匿名会话，Toast提示「已同步X个项目」

---

### 2.2 混合类型组合规则（修订 §2.2）

**新增内容：**

#### 合法组合规则表（9组合法组合）
| 主类型 | 合法附属 | 组合说明 | 特殊处理 |
|--------|---------|---------|---------|
| A买卖 | B备忘录、G担保 | 买卖为主+意向/担保 | 合并担保条款 |
| A买卖 | H债权、I居间 | 买卖为主+债权/居间 | 分章节呈现 |
| B备忘录 | A买卖、C投资、D合作 | 备忘录为主+后续发展 | 标注「意向性文件」 |
| C股权转让 | D合作、G担保 | 股权交易+合作/质押 | 独立章节 |
| C增资 | A买卖、I居间 | 增资为主+对赌/居间 | 对赌单独风险提示 |
| D合作 | C投资、F知识产权 | 合作为主+投资/IP | 分模块独立章节 |
| E劳动 | F知识产权、G担保 | 劳动关系+竞业/保密 | 竞业单独风险提示 |
| F知识产权 | G担保、H债权 | IP授权+质押/债权 | 质押需额外确认 |
| G担保 | C投资、H债权 | 担保为主+关联主债权 | 必须确认主债权 |
| I居间 | A买卖、D合作 | 居间为主+基础交易 | 佣金单独提示 |

**核心规则：**
1. 主类型决定访谈框架
2. 附属类型最多2个（避免访谈过长）
3. 附属类型只追加专属要素，不重复通用要素
4. 系统预置组合规则表，非法组合时主动提示

### 2.3 /回溯指令（修订 §2.3.2）

**行为定义（时光机模式）：**
1. 展示当前项目完整历史快照列表
2. 用户选择回退到任意历史节点
3. 回退后：访谈记录表恢复、对话历史截断、后续对话作废
4. 快照策略：每轮问答后自动生成，保留最近20个

**注意事项：**
- 回溯操作不可逆
- 回退到 `outline_generated` 后可继续访谈或重新生成大纲

---

### 2.4 AI合同文本生成（新增 §2.7、§4.6）

**触发条件：**
- 用户执行 `/导出` 或点击「生成合同」按钮

**生成流程：**
```
收集访谈快照 → 调用AI生成合同文本 → 插入风险标注 → 展示预览
```

**风险标注要求：**
- 高风险条款用 ⚠️ 标记
- 合同末尾独立「风险提示」章节
- 必含免责声明：「本文档仅供参考，不构成法律意见，重大交易请咨询专业律师」

**Token成本控制：**
- 目标 ≤ 5元/份合同
- 实际预估约1.7元/份
- 优化策略：上下文复用、分段生成、冷启动预加载

### 2.5 团队权限体系（新增 §4.7、§5.6-5.8）

**角色定义：**

| 角色 | 代码 | 描述 |
|------|------|------|
| 管理员 | Admin | 项目所有者，可管理成员、修改权限、删除项目 |
| 编辑者 | Editor | 可编辑内容、导出文档、管理成员（子权限） |
| 查看者 | Viewer | 仅可查看项目和文档，不可编辑 |

**权限矩阵：**

| 操作 | Admin | Editor | Viewer |
|------|-------|--------|--------|
| 查看项目 | ✅ | ✅ | ✅ |
| 编辑访谈内容 | ✅ | ✅ | ❌ |
| 编辑大纲/合同文本 | ✅ | ✅ | ❌ |
| 导出文档 | ✅ | ✅ | ❌ |
| 添加/移除成员 | ✅ | ✅ | ❌ |
| 修改成员权限 | ✅ | ✅ | ❌ |
| 删除项目 | ✅ | ❌ | ❌ |
| 查看操作日志 | ✅ | ❌ | ❌ |

**审计日志：**
- 记录每次权限变更：操作人、被操作人、变更前角色、变更后角色、时间戳
- Admin可查看项目操作历史

### 2.6 数据库表新增（新增 §5.6-5.9）

| 新表 | 说明 |
|------|------|
| team_members | 团队成员表（project_id + user_id + role） |

**chat_history表新增字段：**
- message_type：question/answer/fact_update/risk_alert/system
- parent_message_id：对话树结构
- metadata：结构化解析结果

### 2.7 接口清单补全（35个接口）

**按模块统计：**

| 模块 | 接口数 | 核心接口 |
|------|--------|----------|
| 认证 | 6 | register, login, wechat, refresh, logout, me |
| 项目 | 7 | create, list, detail, update, delete, restore, snapshots |
| 访谈 | 5 | question, answer, snapshot, reset, rollback |
| 大纲 | 4 | get, generate, edit, reorder |
| 合同 | 4 | generate, get, edit, copy |
| 导出 | 2 | export, history |
| 团队 | 4 | members, invite, update_role, remove |
| 审计 | 1 | audit-logs |
| 文件 | 2 | upload, download |

**关键接口说明：**

1. **`POST /api/v1/projects/:id/interview/answer`** — 提交回答，返回AI解析结果+下一题
2. **`POST /api/v1/projects/:id/interview/rollback`** — 回溯到历史快照
3. **`POST /api/v1/projects/:id/contract/generate`** — 生成合同文本（含风险标注）
4. **`POST /api/v1/projects/:id/export`** — 导出文档（匿名用户触发401）
5. **`PATCH /api/v1/projects/:id/members/:member_id`** — 修改成员角色（写审计日志）

### 3.2 错误处理规范（§11）
| 场景 | 处理策略 |
|------|----------|
| AI响应超时（>30s） | 返回「生成中」状态，前端轮询 |
| AI服务不可用 | 降级为「大纲模式」 |
| 导出触发但未登录 | 弹出登录引导弹窗 |
| 非法类型组合 | 前端校验，阻止提交 |

### 3.3 成本估算（§12）
| 环节 | Token消耗 | 成本（元） |
|------|-----------|-----------|
| 访谈提问（每轮） | 500 | 0.01 |
| 访谈回答解析（每轮） | 1000 | 0.02 |
| 大纲生成 | 2000 | 0.04 |
| 风险识别 | 1500 | 0.03 |
| 合同文本生成 | 8000 | 1.60 |
| **单份合同总计** | **约13000** | **约1.70元** |

### 3.4 数据安全与隐私合规（§13）
- 数据收集：最小化原则
- 数据存储：加密存储、定期清理
- 用户权利：删除、导出、被遗忘权
- 合规声明：不构成法律意见
