# 衡简叙约 核心接口清单 V1.1

配套文档：衡简叙约 访谈式智能合同生成系统 PRD V1.1
接口风格：RESTful JSON
统一前缀：/api/v1
认证方式：Bearer Token（Supabase JWT）
统一返回格式：
```json
{
  "code": 0,
  "msg": "提示信息",
  "data": {}
}
```

---

## 一、认证模块

### 1.1 用户注册
- **接口**：`POST /api/v1/auth/register`
- **描述**：手机号注册
- **请求体**：
```json
{
  "phone": "13800138000",
  "code": "123456",
  "nickname": "张三"
}
```
- **响应**：
```json
{
  "code": 0,
  "data": {
    "user_id": "uuid",
    "access_token": "jwt_token",
    "refresh_token": "refresh_token"
  }
}
```

### 1.2 用户登录
- **接口**：`POST /api/v1/auth/login`
- **描述**：手机号+验证码登录
- **请求体**：
```json
{
  "phone": "13800138000",
  "code": "123456"
}
```
- **响应**：同注册接口

### 1.3 微信授权登录（小程序/App）
- **接口**：`POST /api/v1/auth/wechat`
- **描述**：微信一键登录
- **请求体**：
```json
{
  "code": "wechat_auth_code",
  "platform": "wechat_miniapp"
}
```
- **响应**：同注册接口

### 1.4 刷新Token
- **接口**：`POST /api/v1/auth/refresh`
- **描述**：使用refresh_token换取新access_token
- **请求体**：
```json
{
  "refresh_token": "token_string"
}
```

### 1.5 退出登录
- **接口**：`POST /api/v1/auth/logout`
- **描述**：使当前token失效
- **请求头**：Authorization: Bearer {token}

### 1.6 获取当前用户信息
- **接口**：`GET /api/v1/auth/me`
- **描述**：获取当前登录用户详细信息
- **响应**：
```json
{
  "code": 0,
  "data": {
    "user_id": "uuid",
    "nickname": "张三",
    "avatar_url": "https://...",
    "login_type": "phone",
    "created_at": "2026-08-16T10:00:00Z"
  }
}
```

## 二、项目模块

### 2.1 创建项目
- **接口**：`POST /api/v1/projects`
- **描述**：创建新的法律文件项目
- **请求体**：
```json
{
  "project_name": "XX买卖合同",
  "main_type": "A",
  "attach_types": ["B"]
}
```
- **响应**：
```json
{
  "code": 0,
  "data": {
    "project_id": "uuid",
    "status": "init",
    "main_type": "A",
    "attach_types": ["B"]
  }
}
```

### 2.2 获取项目列表
- **接口**：`GET /api/v1/projects`
- **描述**：分页获取用户项目列表
- **查询参数**：
  - page: 页码（默认1）
  - size: 每页数量（默认20）
  - status: 状态筛选（可选）
- **响应**：
```json
{
  "code": 0,
  "data": {
    "list": [...],
    "total": 100,
    "page": 1,
    "size": 20
  }
}
```

### 2.3 获取项目详情
- **接口**：`GET /api/v1/projects/:project_id`
- **描述**：获取项目完整信息
- **响应**：
```json
{
  "code": 0,
  "data": {
    "project_id": "uuid",
    "project_name": "XX买卖合同",
    "main_type": "A",
    "attach_types": ["B"],
    "status": "interviewing",
    "created_at": "2026-08-16T10:00:00Z",
    "updated_at": "2026-08-16T11:30:00Z",
    "owner_id": "uuid"
  }
}
```

### 2.4 更新项目基本信息
- **接口**：`PATCH /api/v1/projects/:project_id`
- **描述**：修改项目名称等基本信息
- **请求体**：
```json
{
  "project_name": "修改后的名称"
}
```

### 2.5 删除项目（软删除）
- **接口**：`DELETE /api/v1/projects/:project_id`
- **描述**：软删除项目
- **响应**：
```json
{
  "code": 0,
  "data": {
    "is_deleted": true
  }
}
```

### 2.6 恢复已删除项目
- **接口**：`POST /api/v1/projects/:project_id/restore`
- **描述**：恢复软删除的项目
- **响应**：
```json
{
  "code": 0,
  "data": {
    "is_deleted": false
  }
}
```

### 2.7 获取项目快照历史
- **接口**：`GET /api/v1/projects/:project_id/snapshots`
- **描述**：获取项目访谈快照列表（用于回溯功能）
- **响应**：
```json
{
  "code": 0,
  "data": {
    "snapshots": [
      {
        "snapshot_id": "uuid",
        "snapshot_at": "2026-08-16T10:30:00Z",
        "confirmed_facts_count": 5,
        "pending_facts_count": 2,
        "risk_count": 3
      }
    ]
  }
}
```

## 三、访谈模块

### 3.1 获取当前访谈问题
- **接口**：`GET /api/v1/projects/:project_id/interview/question`
- **描述**：获取下一轮访谈问题
- **响应**：
```json
{
  "code": 0,
  "data": {
    "question_id": "uuid",
    "question_text": "请说明买卖标的物的具体规格和数量",
    "category": "标的物",
    "required": true
  }
}
```

### 3.2 提交访谈回答
- **接口**：`POST /api/v1/projects/:project_id/interview/answer`
- **描述**：提交用户回答，触发AI解析
- **请求体**：
```json
{
  "question_id": "uuid",
  "answer_text": "标的物为型号X的机械设备，数量10台，单价5万元"
}
```
- **响应**：
```json
{
  "code": 0,
  "data": {
    "message_id": "uuid",
    "next_question": {
      "question_id": "uuid",
      "question_text": "请说明交付时间和地点"
    },
    "fact_update": {
      "confirmed_facts": [
        {"field": "标的物规格", "value": "型号X"}
      ],
      "pending_facts": [],
      "new_risks": []
    },
    "snapshot_saved": true
  }
}
```

### 3.3 获取访谈记录表
- **接口**：`GET /api/v1/projects/:project_id/interview/snapshot`
- **描述**：获取当前访谈快照（已确认要素、待确认要素、风险清单）
- **响应**：
```json
{
  "code": 0,
  "data": {
    "confirmed_facts": [
      {"field": "标的物", "value": "型号X机械设备10台", "source": "用户回答"}
    ],
    "pending_facts": [
      {"field": "交付时间", "value": null, "reason": "尚未确认"}
    ],
    "risk_list": [
      {
        "risk_id": "uuid",
        "title": "交付时间不明确",
        "level": "medium",
        "description": "合同未明确约定交付时间，可能导致履约争议",
        "suggestion": "建议补充具体交付时间节点"
      }
    ]
  }
}
```

### 3.4 执行重置指令
- **接口**：`POST /api/v1/projects/:project_id/interview/reset`
- **描述**：清空当前项目访谈状态
- **响应**：
```json
{
  "code": 0,
  "data": {
    "status": "init"
  }
}
```

### 3.5 执行回溯指令
- **接口**：`POST /api/v1/projects/:project_id/interview/rollback`
- **描述**：回退到指定历史快照
- **请求体**：
```json
{
  "snapshot_id": "uuid"
}
```
- **响应**：
```json
{
  "code": 0,
  "data": {
    "status": "interviewing",
    "restored_snapshot": {...}
  }
}
```

## 五、合同文本模块

- **接口**：`POST /api/v1/projects/:project_id/contract/generate`
- **描述**：AI生成完整合同文本
- **响应**：
```json
{
  "code": 0,
  "data": {
    "contract_id": "uuid",
    "content": "合同正文内容...",
    "risk_section": "【风险提示】\n1. 交付时间不明确...\n2. ...",
    "disclaimer": "本文档仅供参考，不构成法律意见，重大交易请咨询专业律师",
    "generated_at": "2026-08-16T12:00:00Z"
  }
}
```

### 5.2 获取合同文本
- **接口**：`GET /api/v1/projects/:project_id/contract`
- **描述**：获取已生成的合同文本
- **响应**：同生成接口

### 5.3 编辑合同文本
- **接口**：`PATCH /api/v1/projects/:project_id/contract`
- **描述**：用户手动修改合同文本
- **请求体**：
```json
{
  "content": "修改后的合同正文..."
}
```

### 5.4 复制合同条款
- **接口**：`POST /api/v1/projects/:project_id/contract/copy`
- **描述**：复制指定章节内容到剪贴板
- **请求体**：
```json
{
  "chapter_id": "uuid"
}
```
- **注意**：匿名用户触发此接口时返回401，提示登录

## 十、错误码定义

| 错误码 | 含义 | 说明 |
|--------|------|------|
| 0 | 成功 | - |
| 1001 | 参数错误 | 请求参数不合法 |
| 1002 | 权限不足 | 当前用户无操作权限 |
| 1003 | 资源不存在 | 请求的资源ID不存在 |
| 1004 | 重复操作 | 操作已被执行过 |
| 2001 | 未登录 | 需要登录后操作 |
| 2002 | Token过期 | 登录态已过期，请重新登录 |
| 3001 | AI服务异常 | AI服务暂时不可用 |
| 3002 | AI生成超时 | 请求超时，请稍后重试 |
| 4001 | 项目状态异常 | 当前项目状态不允许此操作 |
| 4002 | 非法类型组合 | 所选主类型与附属类型不兼容 |
