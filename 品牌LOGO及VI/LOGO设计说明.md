## 二、Logo 设计理念

### 核心概念：对话 → 权衡 → 契约

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│    ┌─────────┐              ┌─────────┐                │
│    │  对话   │    →         │  权衡   │                │
│    │  采集   │              │  风险   │                │
│    └────┬────┘              └────┬────┘                │
│         │                        │                     │
│         └──────────┬─────────────┘                     │
│                    ▼                                   │
│            ┌─────────────┐                             │
│            │   平衡点    │  ← 核心交集                 │
│            │  (数据汇聚) │                             │
│            └──────┬──────┘                             │
│                   │                                    │
│                   ▼                                    │
│            ┌─────────────┐                             │
│            │   契约生成  │                             │
│            │  (成果输出) │                             │
│            └─────────────┘                             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 三个设计方案的差异

| 方案 | 特点 | 优势 | 适用场景 |
|------|------|------|---------|
| **方案一：对话契约** | 对话气泡与平衡标尺并置，契约线条强化 | 结构清晰，元素明确 | 需要强调功能性的场景 |
| **方案二：平衡对话** ⭐ | 双向对话汇聚中心圆点，弧线为契约 | 构图均衡，寓意深刻 | **推荐**：品牌主标识 |
| **方案三：抽象融合** | 几何化组合，现代感强 | 简洁抽象，易识别 | 小尺寸应用、图标 |

## 三、推荐方案详解：「平衡对话」

### 图形构成（由外到内）

```
┌─────────────────────────────────────┐
│                                     │
│         ┌─────────────┐             │
│        ╱               ╲            │
│       │   对话气泡     │            │
│       │  (左)   (右)  │             │
│        ╲      ●      ╱             │
│         └──────┬──────┘             │
│                │                    │
│         ┌──────┴──────┐             │
│         │   契约弧线   │             │
│         └─────────────┘             │
│                                     │
└─────────────────────────────────────┘
```

1. **圆形外框**
   - 象征完整、闭环的契约关系
   - 传达品牌专业、可信的形象
   - 适用于各种尺寸的缩放

2. **双向对话气泡**
   - 左右对称，代表"访谈式采集"
   - 体现用户与系统的对话交互
   - 填充色透明度营造层次感

3. **中心平衡圆**
   - 对话汇聚的核心点
   - 象征权衡权责、识别风险
   - 品牌主色填充，视觉焦点

4. **契约弧线**
   - 下方弧线象征契约约束
   - 双层弧线增加精致度
   - 暗示法律文书的签署

### 色彩运用

| 元素 | 颜色 | 语义 |
|------|------|------|
| 对话气泡 | `#4A7C9B` 20% 透明度 | 理性、审慎、信任 |
| 中心圆 | `#4A7C9B` 实色 | 品牌核心、视觉焦点 |
| 外框/弧线 | `#2C2F36` | 专业、稳重、权威 |
| 次要弧线 | `#4A7C9B` 60% 透明度 | 层次、细节 |

## 四、字体使用建议

### 中文品牌名称

```
推荐使用：Noto Sans SC
字重：Medium (500) 或 SemiBold (600)
理由：现代简洁，适合商务场景，免费商用
```

### 备选中文字体

| 字体 | 风格 | 适用场景 |
|------|------|---------|
| **思源黑体** | 现代中性 | 正文、UI |
| **霞鹜文楷** | 手写温度 | 品牌故事、宣传册 |
| **思源宋体** | 传统稳重 | 法律文件、正式场合 |

### 英文品牌名称

```
推荐使用：Noto Sans SC（无衬线）
备选：Inter（更现代）
字重：Regular (400)
理由：清晰易读，与中文协调
```

### 品牌Slogan

```
推荐使用：Noto Sans SC
字重：Light (300) 或 Regular (400)
字号：比品牌名小 40-50%
理由：作为辅助信息，不应喧宾夺主
```

## 五、Logo 使用规范

### 安全空间

Logo 周围必须保留不少于 Logo 高度 **25%** 的空白区域。

### 最小尺寸

| 版本 | 最小宽度 | 最小高度 |
|------|---------|---------|
| 横排标识 | 200px | 100px |
| 纯图形 | 80px | 80px |

### 背景使用

| 背景类型 | 使用版本 |
|---------|---------|
| 白色 / 浅灰 | 标准深色版本 |
| 深炭灰 `#2C2F36` | 反白版本 |
| 青蓝色 `#4A7C9B` | 全白版本 |

### 禁止用法

- ❌ 不得拉伸、变形 Logo
- ❌ 不得改变颜色组合
- ❌ 不得添加特效（阴影、渐变、描边等）
- ❌ 不得与其他元素重叠
- ❌ 不得旋转 Logo（除非特殊设计需求）

## 七、给设计师的交接说明

### 需要优化的细节

1. **对话气泡形状**：当前为简化版，可根据实际视觉效果调整圆角半径
2. **中心圆大小**：当前比例约为整体 24%，可适当调整
3. **契约弧线弧度**：当前为二次贝塞尔曲线，可尝试其他曲线形态
4. **字体微调**：建议测试不同字重和字间距的视觉效果
