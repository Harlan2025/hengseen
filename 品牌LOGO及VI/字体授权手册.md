## 二、SIL Open Font License (OFL) 说明

### 允许使用

- ✅ 个人使用
- ✅ 商业使用
- ✅ 嵌入网页（Google Fonts CDN）
- ✅ 嵌入 APP
- ✅ 打印物料
- ✅ 修改字体（需保留授权声明）

### 禁止事项

- ❌ 单独出售字体文件
- ❌ 去除授权声明
- ❌ 以字体名称注册商标

### 使用要求

1. 在作品中保留字体授权声明
2. 不要单独分发字体文件
3. 商业用途无需额外付费

## 六、字体嵌入方式

### 网页嵌入（Google Fonts）

```html
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@300;400;500;600;700&display=swap" rel="stylesheet">
```

```css
body {
  font-family: 'Noto Sans SC', sans-serif;
}
```

### 本地嵌入

```css
@font-face {
  font-family: 'Noto Sans SC';
  src: url('/fonts/NotoSansSC-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
```

## 七、字体使用注意事项

1. **保留授权声明**：在品牌手册或网站上注明字体来源
2. **不要单独分发**：字体文件应随项目一起发布，不可单独出售
3. **商业使用确认**：虽然免费商用，但仍建议查看最新授权条款
4. **字体替换预案**：准备备选字体，防止字体服务中断
