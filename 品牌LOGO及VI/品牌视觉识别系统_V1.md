## 二、LOGO 设计说明

### 核心构成

标识融合四大意象元素，分别对应品牌名称的四个字：

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│    ┌──────────┐     ┌──────────┐     ┌──────────┐  │
│    │          │     │          │     │          │  │
│    │   叙     │  +  │   衡     │  +  │   简     │  │
│    │ 对话气泡 │     │ 平衡标尺 │     │ 简约线条 │  │
│    │          │     │          │     │          │  │
│    └──────────┘     └──────────┘     └──────────┘  │
│                          │                         │
│                    ┌──────────┐                   │
│                    │          │                   │
│                    │   约     │                   │
│                    │ 契约书页 │                   │
│                    │          │                   │
│                    └──────────┘                   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 设计原则

1. **简约克制**：线条干净利落，避免过于厚重尖锐
2. **专业商务**：传达法律服务质感
3. **差异化**：不使用天平、法槌等烂大街法律符号
4. **系统性**：图形与文字可分离使用

## 三、色彩系统

### 主色板

| 颜色名称 | Hex | RGB | 用途 |
|---------|-----|-----|------|
| 深炭灰 Charcoal | `#2C2F36` | 44,47,54 | 主文字、边框、强调元素 |
| 静谧青蓝 Blue | `#4A7C9B` | 74,124,155 | 品牌主色、CTA按钮、图标 |
| 浅青蓝 Pale Blue | `#E8F1F5` | 232,241,245 | 背景点缀、辅助图形 |

### 中性色板

| 颜色名称 | Hex | 用途 |
|---------|-----|------|
| 浅灰 Background | `#F7F8FA` | 页面背景 |
| 边框灰 Border | `#E8ECEF` | 分割线、边框 |
| 次要灰 Muted | `#8A919A` | 次要文字 |
| 深灰 Dark | `#5A616A` | 辅助文字 |

### 色彩语义

- **青蓝**：理性、审慎、信任 → 契合法律服务属性
- **炭灰**：专业、稳重 → 面向企业法务、商事经营者

## 四、字体系统

### 字体选择

| 用途 | 字体 | 字重 | 说明 |
|------|------|------|------|
| 品牌标识 | Playfair Display | 600 | 衬线字体，传递专业可信 |

| Body | 16px | 400 | 1.6 | 正文内容 |
| Caption | 14px | 400 | 1.5 | 说明文字 |
| Small | 12px | 400 | 1.4 | 版权、标签 |

## 六、应用场景规范

### Logo 使用规范

| 场景 | 规范 |
|------|------|
| 浅色背景 | 使用标准深色版本 |
| 深色背景 | 使用反白版本 |
| 品牌主色背景 | 使用全白版本 |
| 最小尺寸 | 图形部分不低于 40px |
| 安全空间 | Logo 周围保留不少于 Logo 高度 25% 的空白 |

### 禁止用法

- ❌ 不得拉伸、变形 Logo
- ❌ 不得改变颜色组合
- ❌ 不得添加特效（阴影、渐变等）
- ❌ 不得与其他元素重叠

## 九、交付说明

本 VI 系统基于以下原则设计：

1. **专业性**：深炭灰 + 静谧青蓝传递法律服务可信度
2. **差异化**：对话气泡+平衡标尺+契约书页的复合意象，避免行业同质化
3. **系统性**：从 Logo、色彩、字体到图标形成完整体系
4. **实用性**：提供多场景应用示例和明确的使用规范
